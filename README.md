📘 Java Basics

This repository is a collection of my Java practice programs while learning the fundamentals of programming and Object-Oriented concepts.
I built this to strengthen my basics and keep everything in one place for revision and improvement.


---

🚀 What’s inside?

You’ll find simple Java programs covering:

Basic input/output

If-else and switch cases

Loops (for, while, do-while)

Functions / methods

Arrays

Basic OOP concepts


Nothing fancy here—just solid fundamentals.


---

🎯 Why this repo exists

I didn’t want to just watch tutorials and forget everything.
So this repo is basically my hands-on practice space where I actually write and test code.

If you’re a beginner, this might help you too.


---

🛠️ How to run the programs

1. Clone the repository



git clone https://github.com/Vedansh-Choubey/Java_Basics.git

2. Open the folder



cd Java_Basics

3. Compile any file



javac FileName.java

4. Run it



java FileName
