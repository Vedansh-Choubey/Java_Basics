🎓 Student Management System

This is a simple Java console project I built while learning the basics of Object-Oriented Programming.

The idea was to go beyond small programs and try something that actually handles data in a structured way—even if it’s basic.


---

🚀 What it can do

  • Add student details

  • Display all students

  • Search a student using ID

  • Runs through a simple menu


---

🧠 What I used here

  • Classes and objects

  • Arrays (to store multiple students)
 
  • Loops and if-else logic

  • Scanner for user input

Nothing fancy, it's just clean and functional.
Basically, core Java fundamentals in action.


---

🛠️ How to run

Compile:

javac StudentManagement.java

Run:

java StudentManagement


---

🖥️ Example

1. Add Student
2. Display Students
3. Search Student
4. Exit

⚠️ Limitations

  • Keeping it real:

  • Only stores up to 5 students

  • No update or delete option

  • Data resets when program closes


So yes, it’s Basic but improves my confidence.
